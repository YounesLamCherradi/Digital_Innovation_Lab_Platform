# 🌐 Digital Innovation Lab Website – Al Akhawayn University

**Developer:** Lamhamedi-Cherardi Younes  
**Live Website:** [Click here to visit](https://innovation.aui.ma)  
**Status:** ✅ Live and maintained by Al Akhawayn University  

This project is the **official website of the Digital Innovation Lab at Al Akhawayn University (AUI)**.  
The lab provides students with the opportunity to **work on innovative projects in AI, cybersecurity, digital identities, and digital public infrastructures**.  
This website was **developed entirely by Lamhamedi-Cherardi Younes** and serves as a central hub for showcasing lab achievements, ongoing projects, and student participation.

---

## 🚀 Project Overview

The **Digital Innovation Lab Website** is designed to:  
- Highlight ongoing and completed **innovation projects** at AUI  
- Showcase **student work, publications, and lab achievements**  
- Provide a **user-friendly admin interface** for managing content  
- Allow students to **explore projects and apply to participate**  
- Offer a **contact platform** for academic and industry collaborations  

This platform demonstrates full-stack development skills, database management, and deployment expertise, while supporting the university’s mission to foster **digital innovation and research excellence**.

---

## 🛠️ Tech Stack

| Component       | Technology                                |
|-----------------|------------------------------------------|
| **Frontend**    | HTML5, CSS3, JavaScript, Bootstrap/Tailwind |
| **Backend**     | Django / Flask                            |
| **Database**    | PostgreSQL / SQLite                       |
| **Web Server**  | Nginx + Gunicorn (Production)            |
| **Version Control** | Git + GitHub                          |

## ✨ Features

- 🌟 **Responsive Design** – Works on desktop, tablet, and mobile  
- 🗂️ **Admin Dashboard** – Manage projects, publications, and lab content  
- 📊 **Project Showcase** – Organized listing of lab projects  
- 📬 **Contact Form** – Easy communication for partnerships and inquiries  
- 👩‍🎓 **Student Participation** – Apply to ongoing projects and showcase achievements
